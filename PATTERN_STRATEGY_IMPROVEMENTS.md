#### **1. Head & Shoulders (H&S)** ⭐⭐⭐⭐⭐
```
Why: BEST reversal pattern (80%+ success rate)
When: After uptrend exhaustion

  Target: 22,490 (150-point pattern height)
```

#### **2. Inverse Head & Shoulders** ⭐⭐⭐⭐⭐
```
Why: Mirror of H&S, equally reliable

```

#### **3. Cup & Handle** ⭐⭐⭐⭐
```
Why: STRONG continuation (bullish)
When: After pullback in uptrend
Entry: Break above handle
Target: Depth of cup

Example:
  22,500 → 22,700 → 22,520 (cup forms)
  22,520 → 22,650 (base)
  22,650 → 22,610 (small pullback = handle)
  22,610 → 22,660 ← LONG HERE!
  Target: 22,840 (cup depth = 180 points)
```

#### **4. Wedges (Rising/Falling)** ⭐⭐⭐⭐
```
Rising Wedge (bearish reversal):
  Higher highs + Highers
  BUT converging (wedge shape)
  Entry: Break below support
  
Falling Wedge (bullish reversal):
  Lower highs + Lower lows
  BUT converging
  Entry: Break above resistance
```

#### **5. Pennants** ⭐⭐⭐
```
Why: Like flags but triangular
When: After strong move
Entry: Break of pennant
Target: Pole height (like flags)

Difference from Flag:
  Flag = parallel consolidation
  Pennant = triangular consolidation
```

#### **6. Triple Top/Bottom** ⭐⭐⭐
```
Why: Stronger than double top/bottom
When: Three failed attempts at level
Entry: Neckline break
Target: 2x pattern height (stronger move!)
```

#### **2. Piercing Line (bullish) / Dark Cloud Cover (bearish)** ⭐⭐⭐⭐
```
Piercing Line:
  Day 1: Large bearish candle
  Day 2: Opens lower, closes >50% into day 1 body
  Signal: Bullish reversal
  
Dark Cloud Cover (opposite):
  Day 1: Large bullish candle
  Day 2: Opens higher, closes >50% into day 1 body
  Signal: Bearish reversal
```

#### **3. Tweezer Top/Bottom** ⭐⭐⭐
```
Tweezer Top:
  Two candles with same high
  Second reverses
  Signal: Bearish reversal
  
Tweezer Bottom (opposite):
  Two candles with same low
  Second reverses
  Signal: Bullish reversal
```

#### **4. Inside Bar** ⭐⭐⭐⭐⭐
```
Why: BEST breakout pattern for intraday!
What: Current bar's range INSIDE previous bar
Entry: Break of mother bar high/low
Success Rate: 70%+ with volume

Example (5-min):
  09:30 bar: 22,500-22,550 (mother bar)
  09:35 bar: 22,510-22,540 (inside bar)
  09:40 bar: Breaks 22,550 ← LONG!
```

#### **5. Pin Bar (Rejection)** ⭐⭐⭐⭐
```
Why: Shows strong rejection at level
Structure:
  - Small body
  - Long wick (2x body minimum)
  - Wick points direction of rejection
  
Bullish Pin: Long lower wick (buyers rejected lows)
Bearish Pin: Long upper wick (sellers rejected highs)
```

```python
# Don't chase extended moves
def check_pullback(df, signal):
    if signal.direction == 'long':
        recent_high = df['high'].rolling(10).max().iloc[-1]
        current = df['close'].iloc[-1]
        pullback_pct = (recent_high - current) / recent_high
        
        if pullback_pct < 0.002:  # Less than 0.2% pullback
            return False, "No pullback - chasing!"
        return True, f"Good: {pullback_pct*100:.1f}% pullback"
```
